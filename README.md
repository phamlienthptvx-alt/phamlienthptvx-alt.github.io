# Lien Pham — English teacher website

A one-page personal site for Lien Pham, English teacher at Vi Xuyen High School in Hà Giang. Content is based on her CV.

## Open the site

Open `index.html` in a browser, or from this folder:

```powershell
start index.html
```

## Sections

- About
- Work experience
- Education and certifications
- Skills, languages, and interests
- Contact
